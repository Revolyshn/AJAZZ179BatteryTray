# AJ179 Battery Tray

Минимальное приложение для Windows 10/11, показывающее заряд AJAZZ AJ179 PRO
прямо на значке в области уведомлений.

## Использование

1. Запустите `AJ179BatteryTray.exe`.
2. Если вместо числа появился `?`, включите мышь в режиме 2.4G и пошевелите её.
3. Левый клик открывает панель заряда; правый клик открывает меню.
4. Автозапуск можно включить в меню. По умолчанию он выключен.

Повторный запуск EXE не создаёт вторую копию, а открывает панель уже работающей.
Параметр `--panel` открывает панель сразу при первом запуске.

Если программу перенесли в другую папку, а автозапуск указывал на старый, уже
удалённый файл, запись автоматически переводится на текущую копию. Если автозапуск
настроен на другую существующую копию, меню показывает «(другая копия)», и запись
меняется только по клику.

Значок монохромный: цифры на прозрачном фоне, `?` при отсутствии данных. Он рисуется
сразу в размере, который Windows использует для трея при текущем масштабе (16 px при
100%, 20 при 125%, 24 при 150%, 32 при 200%). На тёмной панели задач цифры серебристые,
на светлой графитовые; при смене темы Windows значок перерисовывается сам.

Меню «Предупреждать о низком заряде»: выключено или 10/15/20/25/30% (по умолчанию 20%).
Уведомление показывается один раз за разряд, пока мышь на связи, и снова становится
возможным, когда заряд поднимется на 5 пунктов выше порога. Выбор хранится в
`%LOCALAPPDATA%\AJ179BatteryTray\settings.json`.
Панель показывает процент, серебристую шкалу и статус. Esc, крестик
и клик вне панели закрывают её.

Частота опроса приёмника:

- панель открыта: сразу при открытии, затем каждые 5 секунд;
- заряд известен, панель закрыта: каждые 30 секунд;
- приёмник на месте, но телеметрии ещё нет: каждые 10 секунд;
- приёмник не найден: каждые 60 секунд.

Подключение или отключение USB-устройства и выход из сна запускают внеочередную
проверку через 1,5 и 3 секунды соответственно. Кнопка и пункт меню «Обновить сейчас»
работают всегда.

Журнал: `%LOCALAPPDATA%\AJ179BatteryTray\log.txt` (пункт меню «Открыть журнал»).
В него пишутся только смены состояния и ошибки; при 256 КБ файл переименовывается
в `log.1.txt`.

Liquid Glass стилизован градиентами, бликами и скруглениями. Фон всей панели:
монохромная размытая иллюстрация AJAZZ, без отдельной картинки и без размытия рабочего
стола. JetBrains Mono Regular/Bold встроены в EXE и не устанавливаются в Windows.
Лицензия шрифта OFL: `src/AJ179BatteryTray/Assets/JetBrainsMono-OFL.txt` (копия
лежит рядом с EXE). Иллюстрация предоставлена пользователем. Утилита неофициальная.

## Поддерживаемое устройство

- VID: `0x3151`
- Приёмник 2.4G: USB product `AJAZZ 2.4G 8K`, PID `0x402D` (также `0x4027`),
  проверенная ревизия `3.0`
- Мышь на кабеле: USB product `AJAZZ AJ179 PRO`, PID `0x4026`, ревизия `3.3`
- HID collection для опроса: usage page `0xFFFF`, usage `0x0002`, interface `MI_02`

Приложение отправляет только временный статусный запрос `0xF7` и только приёмнику.
Оно не записывает настройки, не входит в bootloader и не обновляет прошивку.

Мышь на кабеле никогда не опрашивается: пока она получает `0xF7` напрямую, её прошивка
перестаёт отдавать клики (курсор при этом двигается). Версии до 1.4.0 опрашивали её, если
она была подключена кабелем.

Если приёмник не отдаёт телеметрию, сохраняется последнее известное значение
текущего сеанса. Неизвестный заряд не подменяется нулём. Оставшееся время работы не
вычисляется по недоступным данным.

### Подключение по кабелю

В ответе приёмника на `0xF7` признака зарядки нет: это сходится в трёх независимых
источниках (разбор ответа в официальном GearHub, ajazz-control-center, Aj179PStat).
Зато мышь, подключённая кабелем, появляется в системе как отдельное USB-устройство
`AJAZZ AJ179 PRO` (PID `0x4026`, ревизия 3.3), а приёмник называет себя `AJAZZ 2.4G 8K`
(PID `0x402D`, ревизия 3.0). Поэтому приложение сообщает только факт подключения по
кабелю и ничего не утверждает о зарядке (мышь может заряжаться и от док-станции, этого
по USB не видно):

- панель пишет «Подключена по кабелю», подсказка в трее дополняется «· по кабелю»;
- процент по кабелю не передаётся, показывается последнее известное значение или `--`;
- предупреждение о низком заряде на кабеле не показывается;
- опрашивается только приёмник; мышь на кабеле только обнаруживается.
## Структура

- `src/AJ179BatteryTray`: приложение (WinForms, .NET 10, HidSharp).
- `tests/AJ179BatteryTray.Tests`: xUnit-тесты протокола, автозапуска, опроса, настроек и значка.
- `art/icon`: SVG-исходники значка приложения и скрипт `build-icon.ps1`

- `.github/workflows/build.yml`: CI на GitHub Actions.
- `CHANGELOG.md`: изменения по версиям; из него берётся текст релиза.

## Сборка

Требуется .NET 10 SDK (версия закреплена в `global.json`):

```powershell
./publish.ps1
```

Скрипт прогоняет тесты, публикует single-file EXE в `artifacts/publish/<вариант>` и
копирует его в корень репозитория. Если программа запущена, её EXE переименовывается
в `AJ179BatteryTray.old.exe`: выйдите из неё через меню и запустите снова.

Варианты:

| Вариант | Размер | Требования |
|---|---|---|
| `SelfContained` (по умолчанию) | ~50 МБ | любая Windows 10/11 x64 |
| `FrameworkDependent` | ~1,3 МБ | установлен .NET 10 Desktop Runtime x64 |

```powershell
./publish.ps1 -Variant FrameworkDependent
```

Без рантайма компактный EXE при запуске покажет окно Windows со ссылкой на загрузку
.NET Desktop Runtime. Только тесты:

```powershell
dotnet test AJ179BatteryTray.slnx
```

## CI и релизы

`build.yml` на каждый push в `main` и pull request прогоняет тесты на `windows-latest` и
собирает оба варианта в артефакт `AJ179BatteryTray` (EXE, лицензия шрифта, `SHA256SUMS.txt`).
Тег `vX.Y.Z` дополнительно проверяет, что он совпадает с `<Version>` в csproj, и создаёт
GitHub Release с текстом из раздела `## X.Y.Z` в `CHANGELOG.md`.

Порядок выпуска: поднять `<Version>`, добавить раздел в `CHANGELOG.md`, закоммитить,
`git tag vX.Y.Z`, `git push --follow-tags`.

## Подпись EXE

EXE не подписан, поэтому при первом запуске скачанного файла SmartScreen может показать
«Windows защитила ваш компьютер» («Подробнее» → «Выполнить в любом случае»). Решение:
не подписывать.

- Самоподписанный сертификат SmartScreen не убирает: ему доверяет только машина, где
  сертификат вручную добавлен в доверенные.
- Убрать предупреждение может только платная подпись от доверенного центра (OV/EV-сертификат
  или облачная подпись Microsoft); для личной утилиты это не окупается.
- Целостность скачанного файла можно проверить по `SHA256SUMS.txt` из релиза:
  `Get-FileHash AJ179BatteryTray.exe`.
